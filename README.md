# Nutrition & Fitness Bot

Премиальное Telegram-приложение для питания и тренировок (aiogram 3 +
PostgreSQL + Claude API). Пользователь проходит онбординг, бот считает
суточную норму калорий/БЖУ/воды по формуле Миффлина-Сан Жеора, дальше —
фото-распознавание еды, трекер воды, тренировки, аналитика прогресса и
геймификация (см. «Дорожная карта» ниже — реализовано пока не всё).

Также сохранён старый функционал: свободный чат с Claude (если пользователь
не в сценарии онбординга/меню) и команда **/audit** — Instagram-аудит через
Composio (профиль, метрики за 30 дней, последние посты → PDF).

## Реализовано сейчас

**Этап 2 — распознавание еды по фото (Claude vision):**

- Пользователь присылает фото блюда → Claude определяет блюдо, оценивает вес
  порции и считает калории/БЖУ. Ответ модели приходит не текстом, а вызовом
  инструмента `record_food_analysis` со `strict: true` — JSON гарантированно
  соответствует схеме.
- Карточка результата с ручной коррекцией: `➖/➕` меняют порцию на 25%,
  `⚖️ Указать вес` — точные граммы, `🔄 Не то блюдо` — уточнение названия с
  повторным разбором фото. КБЖУ пересчитывается пропорционально весу.
- Альтернативный ввод текстом («омлет из трёх яиц с сыром») — тот же расчёт
  без фото.
- После сохранения — дневной итог с прогресс-баром и остатком до нормы.
  Тип приёма пищи (завтрак/обед/ужин/перекус) проставляется по времени.

**Этап 1 — фундамент:**

- Структура проекта: `handlers/`, `keyboards/`, `states/`, `models/`,
  `services/`, `utils/`.
- Схема БД (SQLAlchemy, PostgreSQL): `users`, `meals`, `water_log`,
  `workouts`, `workout_log`, `body_measurements`, `progress_photos`,
  `achievements`.
- Онбординг на FSM: пол → возраст → рост → текущий/целевой вес → активность
  → цель → тип питания → аллергии → расчёт и сохранение суточной нормы
  калорий, БЖУ и воды.
- Главное меню (`📷 Добавить еду | 💧 Вода | 🏋️ Тренировка | 📊 Прогресс |
  🍽️ Что съесть | ⚙️ Профиль`) — работают «Добавить еду» и «Профиль»,
  остальные разделы пока заглушки (следующие этапы).
- Расчётные формулы вынесены в `utils/` и покрыты тестами (41 тест).

## Дорожная карта (следующие этапы, ещё не реализовано)

- Ввод еды голосом (Whisper) и по штрихкоду / поиском по базе продуктов.
- Дневная аналитика: «правило тарелки», умные рекомендации следующего
  приёма пищи под остаток БЖУ.
- Тренировки: программы по цели×локации×уровню, MET-расчёт калорий, таймер
  отдыха, кардио отдельно от силовых.
- Прогресс тела: замеры, фото «до/после», графики (matplotlib/plotly).
- Геймификация: streak, еженедельная сводка, напоминания через
  APScheduler, достижения/бейджи.

## Что понадобится

1. **Токен бота** от [@BotFather](https://t.me/BotFather) — он у вас уже есть.
2. **API-ключ Anthropic** — получить на https://console.anthropic.com/settings/keys
   (нужна регистрация; у новых аккаунтов обычно есть небольшой бесплатный лимit
   для старта, дальше — по мере использования, привязка карты).
3. Python 3.10+.
4. **PostgreSQL** (локально или на сервере) — хранит профили, приёмы пищи,
   тренировки и прогресс.
5. *(Только для команды /audit)* аккаунт на [app.composio.dev](https://app.composio.dev)
   и Instagram **Business или Creator**-аккаунт, привязанный к Facebook-странице
   (обычный личный Instagram не поддерживается Instagram Graph API).

## Шаг 1. Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Шаг 2. Настройка секретов

```bash
cp .env.example .env
```

Откройте `.env` в редакторе и впишите:

```
BOT_TOKEN=ваш_токен_от_BotFather
ANTHROPIC_API_KEY=ваш_ключ_с_console.anthropic.com
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/nutrition_bot
```

Файл `.env` не попадёт в git (он уже в `.gitignore`) — никогда не публикуйте
токены в коде или в открытых репозиториях.

Создайте базу данных (один раз):

```bash
createdb nutrition_bot   # или: psql -c "CREATE DATABASE nutrition_bot;"
```

Таблицы создаются автоматически при первом запуске бота (`bot.py` вызывает
`init_models()`). Это удобно для разработки; для продакшена и изменений
схемы в будущем стоит перейти на миграции (например, Alembic).

## Шаг 3. Запуск локально (проверить, что всё работает)

```bash
python bot.py
```

В консоли появится `Бот запускается...`. Откройте своего бота в Telegram и
напишите ему что-нибудь — должен прийти ответ от Claude. Команда `/reset`
очищает историю диалога. Остановить бота — `Ctrl+C`.

Пока в терминале запущен `bot.py`, бот работает. Если закрыть терминал —
бот перестанет отвечать. Чтобы он работал постоянно (24/7), нужен сервер —
см. следующий шаг.

## Шаг 4. Запуск на сервере (VPS) для работы 24/7

1. Арендуйте VPS (например, Ubuntu 22.04/24.04) у любого провайдера.
2. Скопируйте на сервер файлы проекта (`git clone` вашего репозитория или
   `scp`).
3. На сервере выполните шаги 1–2 из этого README (venv, зависимости, `.env`).
4. Настройте автозапуск через systemd — в репозитории есть готовый шаблон
   `telegram-bot.service`:

   ```bash
   sudo cp telegram-bot.service /etc/systemd/system/
   # отредактируйте пути (User, WorkingDirectory, ExecStart) под свой сервер
   sudo systemctl daemon-reload
   sudo systemctl enable --now telegram-bot
   ```

5. Проверить статус и логи:

   ```bash
   sudo systemctl status telegram-bot
   sudo journalctl -u telegram-bot -f
   ```

Теперь бот будет работать постоянно и автоматически перезапускаться при сбое
или перезагрузке сервера.

## Шаг 5. Настройка Instagram-аудита (команда /audit, необязательно)

1. На сервере установите системный шрифт с кириллицей (для генерации PDF):

   ```bash
   sudo apt install -y fonts-dejavu-core
   ```

2. Зарегистрируйтесь на [app.composio.dev](https://app.composio.dev) и создайте
   API-ключ: Settings -> API Keys. Впишите его в `.env`:

   ```
   COMPOSIO_API_KEY=ваш_ключ_с_app.composio.dev
   ```

3. В том же интерфейсе Composio: Connected Accounts -> Instagram -> Connect,
   авторизуйтесь через Facebook и подтвердите доступ к вашей Business/Creator-
   странице. Подключение сохраняется на стороне Composio — боту не нужно
   ничего дополнительно настраивать, он найдёт его сам.

4. Перезапустите бота (`sudo systemctl restart telegram-bot` на сервере, или
   заново `python bot.py` локально) и напишите ему `/audit`.

Бот соберёт данные, попросит Claude их проанализировать и через 30–60 секунд
пришлёт PDF с разбором профиля, топ-постами, стратегией по контенту и планом
на 90 дней.

**Если что-то пошло не так:**
- «Нет активного подключения Instagram» — переподключите аккаунт в
  Connected Accounts на app.composio.dev (шаг 3).
- «Не найден шрифт с поддержкой кириллицы» — выполните шаг 1.
- Личный (не Business/Creator) аккаунт Instagram не поддерживается — это
  ограничение самого Instagram Graph API, не бота.

## Настройки (необязательно)

Всё в `.env`, можно раскомментировать и поменять:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `CLAUDE_MODEL` | `claude-opus-5` | Модель Claude. Для более дешёвых/быстрых ответов можно поставить `claude-haiku-4-5`. |
| `SYSTEM_PROMPT` | дружелюбный ассистент | "Личность" и инструкции для бота. |
| `MAX_HISTORY_MESSAGES` | `20` | Сколько последних сообщений диалога помнит бот. |
| `MAX_TOKENS` | `2048` | Максимальная длина одного ответа. |
| `COMPOSIO_API_KEY` | — | Ключ Composio для команды /audit (см. шаг 5). |
| `DATABASE_URL` | `postgresql+asyncpg://postgres:postgres@localhost:5432/nutrition_bot` | Строка подключения к PostgreSQL. |
| `VISION_MODEL` | `claude-opus-5` | Модель для распознавания еды по фото. |

## Структура проекта

- `bot.py` — точка входа: инициализирует БД, подключает роутеры, стартует polling.
- `db.py` — асинхронное подключение к PostgreSQL (SQLAlchemy) и создание таблиц.
- `config.py` — чтение настроек из `.env`.
- `models/` — схема БД (SQLAlchemy): `user.py`, `meal.py`, `water.py`,
  `workout.py`, `body.py`, `achievement.py`.
- `states/` — FSM-состояния (`onboarding.py`, `food.py`).
- `keyboards/` — inline/reply-клавиатуры (`onboarding.py`, `main_menu.py`, `food.py`).
- `services/` — бизнес-логика вне обработчиков:
  - `food_vision.py` — распознавание еды через Claude (vision + strict tool use);
  - `meals.py` — сохранение приёмов пищи и дневные итоги по КБЖУ.
- `handlers/` — обработчики апдейтов Telegram:
  - `onboarding.py` — пошаговая анкета + расчёт и сохранение нормы КБЖУ/воды;
  - `food.py` — фото/текст → карточка КБЖУ → коррекция порции → сохранение;
  - `menu.py` — кнопки главного меню (реализован «Профиль», остальное — заглушки);
  - `legacy.py` — старые команды: `/reset`, `/audit`, свободный чат с Claude.
- `utils/` — чистые функции с тестами: `formulas.py` (Миффлин-Сан Жеор, TDEE,
  БЖУ, вода), `portions.py` (пересчёт порции), `progress.py` (прогресс-бар),
  `meal_time.py` (тип приёма пищи по времени), `parsing.py` (разбор чисел).
- `tests/` — юнит-тесты формул, порций и разбора ответа vision-модели.
- `claude_client.py` — обращение к Claude API и история диалогов (legacy-чат).
- `composio_instagram.py` — сбор данных Instagram через Composio API.
- `instagram_audit.py` — анализ данных через Claude (команда /audit).
- `report_pdf.py` — сборка PDF-отчёта из результатов аудита.
- `telegram-bot.service` — шаблон systemd-юнита для VPS.
