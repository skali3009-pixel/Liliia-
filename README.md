# Nutrition & Fitness Bot

Telegram-приложение для питания и тренировок: онбординг с расчётом суточной
нормы КБЖУ, распознавание еды по фото через Claude vision, учёт съеденного и
остатка до нормы.

Стек: aiogram 3, PostgreSQL (SQLAlchemy 2.0, async), Claude API (vision).

## Реализовано сейчас

**Онбординг и норма КБЖУ:**

- Пошаговая анкета (FSM): пол, возраст, рост, текущий и целевой вес, уровень
  активности, цель (похудение / поддержание / набор массы / рельеф), тип
  питания, аллергии.
- Расчёт по формуле Миффлина-Сан Жеора + коэффициент активности → суточная
  норма калорий и БЖУ под цель, норма воды (30-40 мл/кг).

**Распознавание еды по фото (Claude vision):**

- Фото блюда → Claude определяет блюдо, оценивает вес порции и считает
  калории/БЖУ. Ответ приходит вызовом инструмента `record_food_analysis` со
  `strict: true` — JSON гарантированно соответствует схеме.
- Карточка результата с ручной коррекцией: `➖/➕` меняют порцию на 25%,
  `⚖️ Указать вес` — точные граммы, `🔄 Не то блюдо` — уточнение названия с
  повторным разбором фото.
- Альтернативный ввод текстом («омлет из трёх яиц с сыром») и **голосом**:
  голосовое расшифровывается через Whisper-совместимый сервис (по умолчанию
  Groq — у него есть бесплатный уровень), дальше тот же расчёт КБЖУ.
- После сохранения — дневной итог с прогресс-баром и остатком до нормы. Тип
  приёма пищи (завтрак/обед/ужин/перекус) проставляется по времени.

**Мини-приложение (Telegram Mini App):** экран «Сегодня» — кольцо калорий,
полоски БЖУ, вода с быстрыми кнопками, список съеденного с правкой веса и
удалением; экран «Добавки» — витамины и лекарства с отметками на сегодня и
формой добавления. Открывается кнопкой «Дневник» рядом с полем ввода.
Подключается одной командой `bash setup-webapp.sh` (бесплатный HTTPS-адрес
из IP сервера либо свой домен).

**Трекер воды в чате:** кнопка `💧 Вода` — стакан / кружка / бутылка,
прогресс до нормы, отмена последнего нажатия.

**Витамины и лекарства:** расписание (каждый день / по дням недели / раз в
N дней), напоминание в заданное время с кнопками «✅ Принял / ⏭ Пропустить»,
отметки и история. Напоминание не придёт, если приём уже отмечен.

**Интерфейс:** главное меню `📷 Добавить еду | 💧 Вода | 🏋️ Тренировка |
📊 Прогресс | 🍽️ Что съесть | ⚙️ Профиль`. Работают «Добавить еду» и
«Профиль», остальные разделы пока заглушки.

## Дорожная карта (следующие этапы)

- Ввод еды по штрихкоду / поиском по базе продуктов.
- Дневная аналитика: «правило тарелки», умные рекомендации следующего приёма
  пищи под остаток БЖУ.
- Напоминания о приёмах пищи и воде (о препаратах — уже работают).
- Тренировки: программы по цели × локации × уровню, видео-демо упражнений,
  таймер отдыха, автоучёт калорий по MET-формуле, кардио отдельно от силовых.
- Прогресс тела: вес и объёмы, фото «до/после», графики динамики.
- Геймификация: streak, еженедельная сводка, напоминания через APScheduler,
  достижения и бейджи.

## Что понадобится

1. **Токен бота** от [@BotFather](https://t.me/BotFather).
2. **API-ключ Anthropic** — https://console.anthropic.com/settings/keys
   (оплачивается отдельно от подписки claude.ai: это разные продукты).
   Без ключа бот тоже запустится — не будет только распознавания еды по фото.
3. **PostgreSQL** — хранит профили, приёмы пищи и прогресс.
4. Python 3.10+.

## Быстрая установка на сервер (одной командой)

```bash
git clone -b claude/bot-power-charging-be0aii https://github.com/skali3009-pixel/Liliia-.git nutrition-bot
cd nutrition-bot
bash install.sh
```

Скрипт сам поставит зависимости и PostgreSQL, создаст базу со сгенерированным
паролем, спросит токен бота и ключ Anthropic, настроит автозапуск через systemd
и проверит, что бот поднялся. Повторный запуск безопасен.

Ниже — то же самое вручную, по шагам.

## Шаг 1. Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Шаг 2. База данных

```bash
sudo apt install -y postgresql                                    # если ещё не стоит
sudo -u postgres psql -c "CREATE USER liliia WITH PASSWORD 'ваш_пароль';"
sudo -u postgres psql -c "CREATE DATABASE nutrition_bot OWNER liliia;"
```

Таблицы создаются автоматически при первом запуске (`bot.py` вызывает
`init_models()`). Для продакшена и будущих изменений схемы стоит перейти на
миграции (Alembic).

## Шаг 3. Настройка секретов

```bash
cp .env.example .env
chmod 600 .env
```

Впишите в `.env`:

```
BOT_TOKEN=ваш_токен_от_BotFather
ANTHROPIC_API_KEY=ваш_ключ_с_console.anthropic.com
DATABASE_URL=postgresql+asyncpg://liliia:ваш_пароль@localhost:5432/nutrition_bot
```

Файл `.env` не попадёт в git (он в `.gitignore`) — никогда не публикуйте
токены в коде и не пересылайте их в переписке.

## Шаг 4. Запуск локально

```bash
python bot.py
```

В консоли появится «Инициализация базы данных…» и «Бот запускается…».
Напишите боту `/start`, пройдите анкету и пришлите фото еды.

## Шаг 5. Запуск на сервере (24/7)

```bash
sudo cp nutrition-bot.service /etc/systemd/system/
sudo nano /etc/systemd/system/nutrition-bot.service   # подставьте User и пути
sudo systemctl daemon-reload
sudo systemctl enable --now nutrition-bot
sudo journalctl -u nutrition-bot -f                    # логи
```

После обновления кода: `git pull && sudo systemctl restart nutrition-bot`.

## Настройки (необязательно)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ Claude для распознавания еды по фото. Без него работает всё остальное. |
| `VOICE_API_KEY` | — | Ключ Whisper-сервиса для голосовых (Groq: console.groq.com/keys). |
| `VOICE_BASE_URL` | `https://api.groq.com/openai/v1` | Endpoint распознавания речи; для OpenAI — `https://api.openai.com/v1`. |
| `VISION_MODEL` | `claude-opus-5` | Модель для распознавания еды по фото. Дешевле/быстрее — `claude-sonnet-5`. |
| `DATABASE_URL` | `postgresql+asyncpg://postgres:postgres@localhost:5432/nutrition_bot` | Строка подключения к PostgreSQL. |

## Тесты

```bash
pytest tests/
```

Покрыты формулы КБЖУ и воды, пересчёт порций, прогресс-бар, разбор ответа
vision-модели и формат самого запроса к Claude.

## Структура проекта

- `bot.py` — точка входа: инициализирует БД, подключает роутеры, стартует polling.
- `db.py` — асинхронное подключение к PostgreSQL и создание таблиц.
- `config.py` — чтение настроек из `.env`.
- `models/` — схема БД: `user.py`, `meal.py`, `water.py`, `workout.py`,
  `body.py`, `achievement.py`, `supplement.py` (таблицы users, meals,
  water_log, workouts, workout_log, body_measurements, progress_photos,
  achievements, supplements, supplement_log).
- `states/` — FSM-состояния (`onboarding.py`, `food.py`).
- `keyboards/` — клавиатуры (`onboarding.py`, `main_menu.py`, `food.py`).
- `services/` — бизнес-логика вне обработчиков:
  - `food_vision.py` — распознавание еды через Claude (vision + strict tool use);
  - `meals.py` — сохранение приёмов пищи и дневные итоги по КБЖУ;
  - `transcription.py` — расшифровка голосовых через Whisper-совместимый API;
  - `water.py` — трекер воды; `supplements.py` — витамины и лекарства.
- `webapp/` — мини-приложение: `auth.py` (проверка подписи Telegram),
  `api.py` (HTTP-API поверх той же базы), `server.py`, `static/` (экран).
- `handlers/` — обработчики апдейтов Telegram:
  - `onboarding.py` — анкета + расчёт и сохранение нормы КБЖУ/воды;
  - `food.py` — фото/текст → карточка КБЖУ → коррекция порции → сохранение;
  - `menu.py` — кнопки главного меню.
- `utils/` — чистые функции с тестами: `formulas.py`, `portions.py`,
  `progress.py`, `meal_time.py`, `parsing.py`.
- `scheduler.py` — планировщик напоминаний (APScheduler, раз в минуту).
- `tests/` — юнит-тесты.
- `install.sh` — установка на сервер одной командой.
- `set-key.sh` — добавить ключ в `.env` и перезапустить бота.
- `setup-webapp.sh` — HTTPS-адрес и подключение мини-приложения.
- `nutrition-bot.service` — шаблон systemd-юнита для VPS.
