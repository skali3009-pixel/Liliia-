# Контент-завод SCALIA

Репозиторий с рабочими материалами для SCALIA (Лилия) — музыканта, который
пишет песни на русском и татарском и делает визуал нейросетями.

Здесь нет приложения, которое надо запускать. Здесь **свод правил, справочники
и готовые тексты**. Завод работает внутри её Telegram-агента Hermes.

## Что внутри

### `hermes-zavod/` — сам завод

Скилл для агента Hermes. Не программа, а инструкции на русском: у агента уже
есть Telegram, модель, память и планировщик.

| Файл | Что в нём |
|---|---|
| `SKILL.md` | Правила: голос, формула пересылаемого поста, формула ролика, скелет подписи, порядок согласования видео, границы |
| `references/songs.md` | 14 песен, припевы, что по какой известно по цифрам |
| `references/platforms.md` | Механика Instagram, TikTok, Shorts и ВК: часы, целевые метрики, татарское направление |
| `references/scenes.md` | Сцены — узнаваемые ситуации, о которых обычно молчат |
| `INSTALL.md` | Установка в профиль `instagram-bot` |

**Установлен на сервер.** Проверен: по запросу «напиши пост в TikTok по песне
„Янымда бул"» выдаёт три варианта с пересылаемой строкой.

### `check.py` — контролёр текста

Проверяет пост по правилам голоса: запрещённые обороты, цепочки эмодзи, слабые
просьбы, хэштеги, длина, наличие короткого самостоятельного высказывания.

```bash
python3 check.py файл.md     # или из stdin
```

Только стандартная библиотека, зависимостей нет.

Проверен на шести реальных постах с известными цифрами пересылок. **Пересылки
предсказывать не умеет** — это сказано в шапке самого файла: разница не в форме
строки, а в том, про чью жизнь она. Ловит механику, не больше.

### `posts/` — готовые тексты

Посты под копирование, с указанием площадки и времени.

### `СТАТУС.md` — где остановились

Состояние работ, что выяснено про сервер, чего не хватает.

## Главное, что выяснено на её данных

- **Охват решают пересылки, не лайки.** 59 пересылок → охват 14 656.
  Ноль пересылок → 79
- Пересылают то, что человек отправит **вместо своих слов** — значит строка
  должна быть про жизнь читателя, а не про жизнь автора
- **Instagram:** 98% охвата — не подписчики. Из 1182 подписчиков за месяц
  пост видят 417. Лучшее время 16:00–20:00 МСК
- **TikTok:** 4200 новых зрителей в неделю бесплатно, но в профиль заходят
  единицы. Пик активности — около полуночи. Целевая метрика не подписчики,
  а видео, снятые на её звук
- **Формат:** ролик с узнаваемой ситуацией даёт 18 000 просмотров против
  200–1000 у обычного музыкального поста

## Чего здесь нет

Завод на aiogram — отдельный Telegram-бот с командой `/zavod` — был написан,
протестирован и **удалён**: на сервере стоит Hermes, и второй бот рядом был бы
третьей архитектурой вместо порядка. Свод правил из него целиком перенесён
в `hermes-zavod/`.
