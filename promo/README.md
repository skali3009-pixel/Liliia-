# Промо-ролик AURA

Вертикальное видео 1080×1920 для Reels, TikTok и Shorts. Снимается с
**живого приложения** на настоящих данных — это не макет и не монтаж из
скриншотов: запускается тот же `webapp/server.py`, что работает на
сервере, и браузер ходит по нему по-настоящему.

Собрать целиком:

    python promo/make.py

Готовый файл — `promo/build/AURA_promo_1080x1920.mp4`. Всё содержимое
папки `build/` порождается заново и в git не хранится.

Когда станет известно имя бота в Telegram, его можно вписать в финальную
карточку:

    python promo/make.py @имя_бота

## Из чего собрано

| файл | что делает |
|---|---|
| `stage.py` | поднимает приложение на localhost и наполняет базу: два месяца веса, отметки цикла, еда, вода, шаги, тренировки |
| `transcode.py` | готовит копии роликов Аи для браузера записи |
| `record.py` | ведёт браузер по сценарию и пишет экран; сам себя проверяет |
| `captions.py` | рисует подписи — браузером, шрифтами проекта |
| `frame.py` | оправа кадра: свет, скругление, кромка |
| `endcard.py` | финальная карточка |
| `assemble.py` | монтаж: обрезка, оправа, подписи, финал |

## Решения, которые принимались осознанно

- **Приложение не должно выглядеть пустым.** Промо на нулях говорит
  «тут нечего делать». Поэтому в базе два месяца жизни, а вес идёт с
  недельной пилой и всплеском перед месячными — той самой картинкой,
  ради которой женский календарь и заведён.

- **Час съёмки выбран, а не достался случайно.** Машина живёт по UTC, и
  в московском времени сейчас ночь: приложение честно здоровается
  «доброй ночи» и говорит, что гепард свернулся клубком. Для промо это
  неверная нота. Пояс сцены выбран так, чтобы «сейчас» приходилось на
  вечер: день почти собран, и «Твой ход» предлагает дело, а не покой.

- **Ролики Аи подменяются только в браузере записи.** Chromium в
  контейнере собран без H.264, и без подмены промо показывало бы
  неподвижную заставку там, где она двигается. Сами файлы в
  `webapp/static/trainer/` не трогаются — правило проекта ставить их как
  есть остаётся в силе.

- **Захват проверяется, а не принимается на веру.** Изредка браузер
  рисует страницу в четверть буфера, а вокруг кладёт ровное серое
  (128,128,128) — такого цвета в тёмной палитре проекта нет нигде, и
  доля этого серого и есть мера. Поймано глазами на третьей записи,
  когда вторая с теми же настройками вышла целой. Испорченный захват
  отбивается, `make.py` снимает заново, до трёх раз.

- **Экран кладётся в кадр целиком.** Телефон — 9:19,5, лента ждёт 9:16.
  Растянуть нельзя (поедут кольца и лицо), обрезать сверху и снизу
  тоже — там шапка и панель вкладок, то есть ровно то, что показываем.
  Свободное место сверху занимает подпись.

- **Подписи рисует браузер.** У ffmpeg нет ни Playfair Display, ни
  разрядки надзаголовка; шрифты проекта приходят в woff2, а его не
  читает и PIL. Подпись чужим шрифтом читалась бы как чужая.

- **Ролик немой, и это не нехватка.** Ленту смотрят без звука, и
  подписи здесь — не костыль, а основной носитель смысла. Свою дорожку
  платформы всё равно предлагают наложить при публикации.

- **Имя бота не выдумано.** В коде оно пустое (узнаётся на ходу,
  `services/identity.py`), и промо с несуществующей ссылкой хуже, чем
  промо без ссылки. Передаётся аргументом.

- **Тексты — по тем же правилам, что техника упражнений и тур:** ни
  обещаний результата, ни диагнозов, одно предложение на подпись. Стоит
  тест (`tests/test_promo_captions.py`).
