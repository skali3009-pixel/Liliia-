## Часть 1. Переключить ветку по умолчанию на `main`

Делается на сайте GitHub, мышкой. Ветки при этом **не удаляются**,
ничего не ломается — меняется только то, что GitHub показывает первым.

1. Открой https://github.com/skali3009-pixel/Liliia-
2. Вверху репозитория — вкладка **Settings** (шестерёнка, справа в ряду
   вкладок).
3. Слева сразу открыт раздел **General**. Пролистай вниз до блока
   **Default branch** — там написано `claude/telegram-bot-setup-gvlv0k`.
4. Справа от названия — кнопка с двумя стрелками **⇄** (переключить).
   Нажми её.
5. В выпадающем списке выбери **`main`** → кнопка **Update**.
6. Появится окошко с предупреждением → **I understand, update the
   default branch**.

После этого скажи — отмечу в `STATUS.md`.

## Часть 2. Проверка файла `/root/s.py`

**Что проверяем:** есть ли файл, сколько в нём строк (должно быть **11**,
если собрался целиком) и что внутри.

**Про пароль:** в файле есть строка входа в почту с паролем. Третья
команда её закрывает — на экран пароль не попадёт.

Вставляй **по одной**, после каждой Enter.

### 1. Есть ли файл, какого размера и когда создан

```
ls -l /root/s.py
```

### 2. Сколько строк собралось (ждём 11)

```
wc -l /root/s.py
```

### 3. Содержимое с номерами строк, пароль скрыт

```
sed 's/login(.*/login(HIDDEN)/' /root/s.py | cat -n
```

## Что присылать

Скриншот после третьей команды.

Если файла нет — первая команда напишет `No such file or directory`.
Это тоже ответ, присылай как есть.

## Что это даст

- **Файл есть и строк 11** → скрипт собрался целиком, смотрим, не
  покалечены ли строки при вставке.
- **Строк меньше 11** → сборка оборвалась, видно, на какой строке.
- **Файла нет** → до сборки дело не дошло, начинаем с чистого листа.
