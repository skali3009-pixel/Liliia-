# Ветка по умолчанию: сам переключить не могу

**Дата:** 21 сентября 2026
**Короткий ответ: НЕ ПОЛУЧИЛОСЬ.** Нужны твои шесть кликов, ниже.

## Почему не могу

Я искал среди своих инструментов для GitHub — **инструмента смены
настроек репозитория у меня нет.**

Что я умею с GitHub: читать файлы, создавать ветки, коммитить, открывать
запросы на слияние, читать задачи. Чего не умею: **менять настройки
репозитория** — а «ветка по умолчанию» это именно настройка, она живёт в
Settings, а не в коде.

Командной строки `gh` (программа GitHub для терминала) и прямого доступа
к их API в этой среде у меня тоже нет — это закрыто по устройству
сессии, не обойти.

Это не «не захотел» и не ошибка доступа к твоему репозиторию: мои права
на запись в него работают, `main` я запушил только что. Закрыт именно
раздел настроек.

## Что проверено (подтверждено командой)

Текущее живое состояние на GitHub:

| Что | Значение |
|---|---|
| Ветка по умолчанию сейчас | `claude/telegram-bot-setup-gvlv0k` |
| `main` существует на сервере | **да**, коммит `f58eaf6` |
| `claude/bot-power-charging-be0aii` | на месте, не тронута |

То есть всё готово к переключению — `main` есть, в ней вся память
проекта. Осталось только указать GitHub, что главной считать её.

## Что нажать (6 кликов, 1 минута)

1. Открой https://github.com/skali3009-pixel/Liliia-
2. Вверху репозитория — вкладка **Settings** (шестерёнка, справа в ряду
   вкладок `Code` / `Issues` / `Pull requests` / … ).
3. Слева сразу открыт раздел **General**. Листай вниз до блока
   **Default branch** — там написано `claude/telegram-bot-setup-gvlv0k`.
4. Справа от названия — кнопка с двумя стрелками **⇄**. Нажми её.
5. В выпадающем списке выбери **`main`** → кнопка **Update**.
6. Выскочит предупреждение → **I understand, update the default
   branch**.

### Это безопасно

- Ветки **не удаляются** — ни одна.
- Код **не меняется**.
- Меняется только то, какую ветку GitHub открывает первой и от какой
  считает новые ветки.
- Если что — переключается обратно теми же шестью кликами.

## Если на телефоне

В мобильном приложении GitHub раздела Settings нет. Нужно открыть сайт
**github.com в браузере** (Chrome и т.п.). Можно попросить «полную
версию сайта» в меню браузера, если вкладка Settings не видна.

## Дальше

Напиши, получилось или нет — отмечу в `STATUS.md`.

Команды для сервера (Этап 1, файл `/root/s.py`) ждут тебя в

можно делать в любом порядке.
