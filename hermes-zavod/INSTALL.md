# Установка завода в Hermes

Завод — это **скилл** для агента Hermes, а не отдельный бот. У агента уже есть
Telegram, модель, память и свой планировщик. Ему нужны инструкции и каталог,
а не второй процесс рядом.

Отправлять в чат **«Контент завод»**, по одной команде за раз.

---

## Шаг 1. Куда класть — выяснено

```
/root/.hermes-insta/.hermes/profiles/instagram-bot/skills/
```

Существуют три папки со скиллами: общая `/root/.hermes/skills/`, общая для
этого экземпляра `/root/.hermes-insta/.hermes/skills/` и профильная. Нужна
**профильная**: рядом с ней лежит `.skills_prompt_snapshot.json` — собранный
промпт скиллов именно профиля `instagram-bot`.

Профильная ещё и правильнее по смыслу: завод нужен одному боту, а не всем.

---

## Шаг 2. Положить скилл

Репозиторий публичный, ключи не нужны.

```
Выполни РОВНО эти команды и верни вывод. Ничего кроме них не делай.

S=/root/.hermes-insta/.hermes/profiles/instagram-bot/skills; cd /tmp && rm -rf zavod-tmp && git clone --depth 1 -b claude/telegram-bot-setup-gvlv0k https://github.com/skali3009-pixel/Liliia-.git zavod-tmp && mkdir -p $S/zavod && cp -r zavod-tmp/hermes-zavod/. $S/zavod/ && rm -f $S/zavod/INSTALL.md && rm -rf /tmp/zavod-tmp && echo "=== СОСЕДИ ПО ПАПКЕ ===" && ls $S && echo "=== ЗАВОД ===" && ls -R $S/zavod
```

Команда заодно покажет, какие скиллы уже лежат рядом. Если там есть другие —
папка живая, всё правильно.

---

## Шаг 3. Перезапустить только свой гейтвей

**Именно `hermes-gateway-insta`, а не `hermes-gateway`.** Второй — другой бот.
AURA не трогаем вообще.

```
systemctl restart hermes-gateway-insta && sleep 4 && systemctl is-active hermes-gateway-insta
```

Должно ответить `active`.

---

## Шаг 4. Проверить

Написать боту обычными словами:

> Напиши пост в TikTok по песне «Янымда бул»

Правильный ответ: **три варианта**, в каждом отдельным абзацем пересылаемая
строка, песня последней строкой, 5–7 хэштегов под поиск.

Если пришёл один вариант без пересылаемой строки — скилл не подхватился.
Проверить шаг 1: папка выбрана не та.

---

## Шаг 5. Напоминания

Крон в Hermes создаётся словами, ничего настраивать не надо. Сначала один раз
отправить в нужном чате:

```
/sethome
```

Потом попросить бота обычным текстом:

> Каждый четверг в 23:30 напоминай мне выложить видео в TikTok — это лучшее
> время по моей статистике. И каждый день в 16:30 напоминай про Instagram.

Проверить: `hermes cron list`.

---

## Что делать со старым ботом на aiogram

В корне репозитория лежит `bot.py` и модули завода — это первая версия,
отдельный бот. **Она не нужна**, если завод встал скиллом: получилась бы третья
архитектура рядом с двумя существующими.

Удалять не надо, пусть лежит в репозитории. На сервер её не ставить.

Ценное из неё уже перенесено: свод правил из `playbook.py` целиком лежит
в `SKILL.md` и `references/platforms.md`.
